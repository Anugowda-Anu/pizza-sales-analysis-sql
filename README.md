# Pizza Sales Analysis using MySQL

## Project Overview

This project analyzes pizza sales data using MySQL to understand sales performance, popular pizza products, and customer ordering patterns.

## Tools Used

* MySQL
* MySQL Workbench

## Key Analysis

* Total revenue and orders
* Total pizzas sold and average order value
* Sales by pizza category and size
* Top-selling and least-selling pizzas
* Orders by hour of the day
* Daily sales trends
* Revenue contribution by pizza category and type

## Project Objectives

* Analyze pizza sales performance
* Identify popular pizza categories and sizes
* Understand ordering patterns
* Practice SQL queries for data analysis

## Files Included

* `query_pizza.sql` — SQL queries for the analysis
